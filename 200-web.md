# Web

Apache serves three things on the party LAN: the PXE boot tree (iPXE fetches almost
everything over HTTP, not TFTP), a browsable games share, and the Windows driver app.
Everything below is written by hand and is the same on every server.

Uses nothing from `/etc/lanparty/env`.

## Packages

```sh run
apt install -y apache2 php libapache2-mod-php
apt install -y php-sqlite3 php-zip        # only for the /windrv app
```

`libapache2-mod-php` enables PHP everywhere by itself -- which is why the games block
(`300-sharing.md`) switches it back off.

## Apache Configuration

Only what every part shares lives here. Each part brings its own file next to it
(`/pxe`: `400-pxe.md`, `/games`: `300-sharing.md`, `/windrv`: `430-pxe-windows.md`, the
portal at `/`: `220-portal.md`, HTTPS: `210-tls.md`).

`/etc/apache2/conf-available/lanparty.conf`
```apache file=/etc/apache2/conf-available/lanparty.conf
# The name every client can resolve (dnsmasq, 140-dns-dhcp.md); the public name with
# its certificate is the HTTPS vhost's (210-tls.md).
ServerName lanparty.lan.party

EnableSendfile On
```

```sh run
a2enconf lanparty
apache2ctl configtest
systemctl reload apache2
```

```sh verify
# Apache runs PHP and its configuration is consistent
systemctl is-active --quiet apache2
apache2ctl -M 2>/dev/null | grep -q php
apache2ctl configtest 2>/dev/null
[ -e /etc/apache2/conf-enabled/lanparty.conf ]
```
